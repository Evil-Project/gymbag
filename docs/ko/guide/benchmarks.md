# 벤치마크 및 성능 비교 (Caddy / Nginx)

Gymbag은 내장 Proof-of-Work WAF, 사용자 지정 및 원격 방화벽 규칙, AI/의심 트래픽 탐지를 활성화한 상태에서도 초고속 HTTPS 리버스 프록시로 동작하도록 설계되었습니다.

## 테스트 환경 및 측정 방법

모든 벤치마크는 동일한 장비와 동일 조건에서 **완전히 동일한 ECDSA P-256 인증서**로 TLS 1.3을 종료하고, `1 KiB`(`1024`바이트)를 반환하는 **동일한 Go HTTP/1.1 업스트림 서버**로 프록시하며 측정했습니다:

| 항목 | 값 |
| :--- | :--- |
| **하드웨어** | Apple M4 (10코어 CPU, 16 GiB RAM) |
| **OS / 런타임** | macOS 26.6.1 (`darwin/arm64`), Go `1.27.0` |
| **비교 대상** | **Gymbag** `v0.1.0`, **Caddy** `v2.11.9`, **Nginx** `1.31.8` |
| **동시성** | `64`개 동시 워커 (HTTP/2는 `8`개 다중화 TCP 연결) |
| **측정 구간** | 시나리오별 `2초` 워밍업 + `8초` 본 측정 (한 번에 하나의 서버만 실행) |
| **업스트림 튜닝** | 세 프록시 모두 유휴 업스트림 keep-alive `1024` 및 액세스 로그 비활성화 (`access_log off` / `level ERROR`) |
| **직접 업스트림 기준** | `143,761 req/s` (평문 HTTP/1.1, p50 `0.342 ms`, p99 `1.817 ms`, 오류 `0`) |

## 핵심 요약

1. **HTTP/1.1 및 HTTP/2 모두에서 Caddy보다 훨씬 빠름**: 전체 WAF를 켠 상태에서도 Gymbag은 Caddy 대비 **HTTP/1.1에서 +32%**, **HTTP/2에서 +63%~+69% 더 높은 RPS**를 기록하며 메모리는 **30% 적게**, 바이너리 크기는 **3.8배 작게** 유지합니다.
2. **C 기반 Nginx에 근접한 처리량**: 메모리 안전한 순수 Go 표준 라이브러리로 구현되었음에도 Nginx HTTP/1.1 처리량의 **85%**에 도달하며 **p99 테일 지연 시간은 Nginx보다 약 2배 낮고**(`3.14 ms` vs `6.20 ms`), HTTP/2는 **74%** 수준입니다.
3. **무시할 수 있는 WAF 검사 오버헤드**: `verify 3` 활성화 시와 `protect off` 순수 프록시 모드의 성능 차이가 측정 오차 범위 내(`72,517` vs `72,479` RPS)입니다.
4. **고속 엣지 차단**: `/.env`, `/wp-admin` 같은 공격 프로브를 TLS 엣지에서 **140,680 req/s**로 즉시 차단해 백엔드 애플리케이션을 완벽히 보호합니다.

## 내부 성능 최적화 구조

- **융합형 제로 클론 HTTPS 파이프라인**: 요청당 호스트 라우팅, 클라이언트 IP, HSTS, WebSocket 여부를 한 번에 해석해 `r.WithContext` 복제 및 중간 헤더/쿠키 맵 할당을 제거했습니다.
- **제로 할당 Aho-Corasick DFA**: 내장 AI 봇, 의심 UA, 쿼리 공격 토큰 및 사용자 `user_agent` 규칙을 대소문자 무관 ASCII DFA(`O(len(input))`)로 사전 컴파일했습니다.
- **O(1) 경로 맵 & 고속 글롭**: 정확 일치 경로는 해시 맵을 사용하고 `prefix*` / `*suffix` / `*sub*`는 정규식 엔진을 우회합니다.
- **64-샤드 속도 제한 및 클리어런스 캐시**: 캐시 라인 정렬된 64개 샤드로 멀티코어 락 경합을 제거했습니다.
- **사전 파싱된 업스트림 & 버퍼 풀**: 라우트 로드 시 업스트림 URL을 미리 파싱하고 32 KiB 버퍼를 `sync.Pool`로 재사용하며 스트리밍 응답(SSE 등)에만 청크 플러시를 수행합니다.
- **정적 응답 사전 렌더링 & 락프리 SNI**: 에셋 ETag와 차단 HTML을 기동 시 생성하고 TLS SNI 인증서를 `atomic.Pointer`로 락 없이 조회합니다.
